# 独立日志前端

用户于 2026-10-07 确认日志前端已从波形操作界面分离。本说明记录源码入口与使用方式，本次目录整理没有重新部署现场服务。

| 文件 | 用途 |
| --- | --- |
| `tools/waveform_log_dashboard.py` | HTTP 服务；可从 SSH 或服务器本机读取查询结果 |
| `tools/waveform_log_dashboard.html` | 日志网页；默认通过 HTTP 服务展示 |
| `tools/query_waveform_mongodb.py` | 只读任务和已存文件查询 |
| `tools/run_waveform_log_dashboard.sh` | 开发机启动入口，可后台启动 |
| `tools/run_waveform_log_dashboard_server.sh` | 服务器本机入口，使用 flock 避免重复启动 |
| `tools/deploy_waveform_log_dashboard.sh` | 现场部署入口，包含上传及自启动配置；仅在部署任务中使用 |

## 本机使用

在项目根目录执行：

```bash
bash tools/run_waveform_log_dashboard.sh
# 或后台启动
bash tools/run_waveform_log_dashboard.sh --background
```

默认本机地址为 `http://127.0.0.1:8765/`。服务器部署脚本配置的共享地址为 `http://192.0.2.2:8765/`，实际可用状态以现场服务为准。

`--source ssh` 使用现有 SSH 连接；`--source local` 适用于服务器本机。用户日期按 Asia/Shanghai 处理。日志和运行状态保留在既有 `logs/` 或部署环境的状态目录中，不进入 Git。
