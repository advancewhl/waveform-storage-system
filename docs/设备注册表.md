# 设备注册表

## 目标

`config/devices.json` 是47台现场基线的单一事实源。`config/devices.candidate.json` 是当前
实验分支用于统一 GUI 的 schema v2 候选源，已无损容纳383台设备，但没有替换正式基线或
生产兼容清单。

注册表支持约 200 台设备；规模测试已用 200 条唯一设备记录通过。容量扩展不等于现场可用，
新 PV 表仍需经过字段核对、差异审查和分批验证。

## 字段和校验

加载器同时支持 schema v1 和 v2。v2 在原字段基础上新增：

- `epics_port_status`：`assumed/configured/verified/failed`；
- `review_status`：`approved/needs_review/rejected`；
- `source_ref`：候选数据来源。

schema v2 允许真实存在的多命名域、大小写敏感 PV、扩展设备类型和多个 PV 共用设备 IP。
设备项包含：

- `device_id`、完整 `pv`、`section`、`order`；
- `epics.host` 和 `epics.port`；
- `enabled`、`selected_by_default`、`acquisition_enabled`；
- `credentials_profile` 和 `paths.remote_data_dir`。

加载时校验设备 ID、PV 和顺序唯一，顺序从 0 连续，PV 规范化结果与
`device_id` 一致，IP/端口合法，并要求采集设备同时处于启用状态。schema v1 继续要求
EPICS主机唯一；schema v2允许经审计的共用IP。凭据只保存配置档名称，
不写密码。

## 常用命令

先激活环境并设置源码路径：

```powershell
conda activate waveform-storage
$env:PYTHONPATH = (Resolve-Path src).Path
```

校验注册表：

```powershell
python tools/device_registry.py validate --registry config/devices.json
python tools/device_registry.py validate --registry config/devices.candidate.json
```

检查当前旧文件是否与注册表一致：

```powershell
python tools/device_registry.py check-legacy `
  --registry config/devices.json `
  --all config/pv_list_ALL.txt `
  --acquisition config/acquisition_pv_list.txt
```

从注册表生成旧格式兼容文件：

```powershell
python tools/device_registry.py generate `
  --registry config/devices.json `
  --all-output config/pv_list_ALL.txt `
  --acquisition-output config/acquisition_pv_list.txt
```

从审计后的 JSON-lines 候选生成 schema v2：

```powershell
python tools/device_registry.py import-candidate `
  --candidate outputs/pv_list_2026-07-26/pv_list_ALL_2026-07-26_candidate.txt `
  --output config/devices.candidate.json
```

导入旧式全量/采集双表时不要直接覆盖正式注册表：

```powershell
python tools/device_registry.py import-legacy `
  --all path/to/new_all.txt `
  --acquisition path/to/new_acquisition.txt `
  --output path/to/devices.candidate.json
```

当前候选结果必须保持383台、377个唯一IP、26个区域、0台启用真实采集。确认端口、设备语义
和现场小批验证后，才逐台修改 `epics_port_status`、`review_status` 和
`acquisition_enabled`；不能直接用候选覆盖 `config/devices.json`。
`config/SWITCH_PV_IP.txt` 暂作为历史输入保留，不由生成器覆盖。
