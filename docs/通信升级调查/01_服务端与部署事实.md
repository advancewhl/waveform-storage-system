建议只读命令：

```bash
date -Is
hostname
uname -a
ps -ef --forest
ss -lntp
readlink -f /proc/<PID>/exe
readlink -f /proc/<PID>/cwd
tr '\0' ' ' < /proc/<PID>/cmdline
sha256sum <实际程序文件>
```

不要执行 `kill`、`systemctl restart`、覆盖文件或修改权限。
