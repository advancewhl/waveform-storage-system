## 为什么不自动回退

如果 candidate 请求已经被服务端接受，但客户端在响应前超时，再自动发送 legacy 请求可能
启动第二个采集任务。实验实现因此只允许操作者明确选择协议；失败后保留 request ID 和状态，
等待查询或人工决策。

## 明日证据回来后的决策

1. 如果生产服务可升级：在服务端增加 v1 adapter 和持久化 task registry；
2. 如果生产服务不可修改：建立独立网关，将 v1 映射为已确认的 legacy 帧；
3. 如果响应/幂等无法确认：GUI 保持 legacy，只统一客户端内部请求、错误和日志；
4. 任一方案都必须提供显式切换、单台灰度、停止条件和现场回滚。
